Exercício 1 — DeadlineService

Criar um sistema de prazos (deadlines) para tarefas.

Dicas (como implementar):
- Começa por pensar: “Onde vou guardar os deadlines?”
- Cria uma estrutura privada dentro do service (ex: um Map ou objeto)
- Usa taskId como chave e date como valor
- Implementa primeiro apenas o armazenamento (setDeadline)
- Depois implementa a lógica de tempo (comparar datas)
- Converte datas para números (timestamp) para facilitar comparações
- Cria uma função auxiliar para obter a data atual
- isExpired(taskId) deve:
→ buscar a data
→ comparar com o tempo atual
→ devolver true/false
- getExpiredTasks() deve:
→ percorrer todos os deadlines
→ filtrar os expirados
→ devolver apenas os taskIds ou tasks
- Implementa por etapas: guardar → comparar → filtrar → devolver

Funções esperadas:
- setDeadline(taskId, date)
- isExpired(taskId)
- getExpiredTasks()

Exercício 3 — AssignmentService

Sistema de atribuição de tarefas a utilizadores.

Dicas (como implementar):
- Primeiro desenha mentalmente a relação:
task → users
user → tasks
- Cria duas estruturas internas:
1) taskToUsers
2) userToTasks
- assignUser deve:
→ adicionar user à task
→ adicionar task ao user
- unassignUser deve:
→ remover user da task
→ remover task do user
- getUsersFromTask → lê taskToUsers
- getTasksFromUser → lê userToTasks
- Implementa primeiro a estrutura
- Depois implementa add
- Depois implementa remove
- Só depois faz as funções de leitura

Funções esperadas:
- assignUser(taskId, userId)
- unassignUser(taskId, userId)
- getUsersFromTask(taskId)
- getTasksFromUser(userId)

Exercício 10 — AutomationRulesService

Sistema de regras automáticas do projeto.

Dicas (como implementar):
- Pensa em regras como “if → then”
- applyRules(task) deve:
→ ler estado da task
→ aplicar regras
- applyUserRules(user) deve:
→ ler estado do user
→ aplicar regras
- Implementa regra a regra, não tudo de uma vez
- Cria funções pequenas para cada regra

Regras:
- Se task ficar COMPLETED → criar log automático
- Se task ficar BLOCKED → notificar
- Se user ficar inactive → remover assignments
- Se task expirar → mover para BLOCKED

Funções:
- applyRules(task)
- applyUserRules(user)
