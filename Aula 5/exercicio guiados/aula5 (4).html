Exercícios Guiados — Static em TypeScript (ENUNCIADO REFATORADO)

Objetivo geral:
Aprender a usar static para:

  • estado global
  • serviços globais
  • configuração central
  • regras partilhadas
  • contadores globais
  • utilitários sem instância
Conceito-chave:
static pertence à classe, não ao objeto.
Existe apenas uma cópia na memória para todo o sistema.

Exercício 1 — Contador global de entidades

Ficheiro: models/BaseEntity.ts

Objetivo: Criar um contador global que conte TODAS as entidades do sistema, incluindo objetos de classes que herdam de BaseEntity.

Funções a implementar:

  • static getTotalEntities(): number

Comportamento obrigatório:

  • O contador deve ser static
  • Deve existir apenas uma variável global
  • Deve ser incrementado no constructor

  • Deve ser acedido por BaseEntity.getTotalEntities()
