Exercícios Guiados — Generics em TypeScript (Projeto Gestão de Tarefas e Utilizadores)

Objetivo geral:
Aprender a usar generics (<T>) para:

  • reutilizar código
  • evitar duplicação
  • criar estruturas flexíveis
  • manter tipagem forte
  • integrar no sistema real de users e tasks
Conceito-chave:
<T> representa um tipo genérico que será definido no uso da classe/função.

Exercício 2 — Cache genérica por ID

Ficheiro: utils/SimpleCache.ts

Contexto:
Cache de:

  • utilizadores por id
  • tarefas por id

Objetivo:
Criar um cache reutilizável.

Dicas:

  • Usar <K, T>
  • K = tipo da chave
  • T = tipo do valor
  • Usar Map<K, T>
export class SimpleCache {

    // CRIAR:
    // private cache: Map

    // IMPLEMENTAR:
    // constructor()

    // IMPLEMENTAR:
    // set(key: K, value: T): void

    // IMPLEMENTAR:
    // get(key: K): T | undefined
}

Teste obrigatório:

// main.ts
const userCache = new SimpleCache();
userCache.set(1, user1);
console.log(userCache.get(1));

const taskCache = new SimpleCache();
taskCache.set(10, task1);
console.log(taskCache.get(10));

Exercício 3 — Favoritos genéricos

Ficheiro: utils/Favorites.ts

Contexto:
Favoritos de utilizadores e tarefas.

Objetivo:
Criar sistema genérico de favoritos.

Dicas:

  • Usar <T>
  • Array interno
  • Evitar duplicados
  • Comparação por referência

Funções obrigatórias:

  • add(item: T)
  • remove(item: T)
  • exists(item: T)
  • getAll()
export class Favorites {

    // CRIAR:
    // private items: T[]

    // IMPLEMENTAR:
    // add(item: T): void

    // IMPLEMENTAR:
    // remove(item: T): void

    // IMPLEMENTAR:
    // exists(item: T): boolean

    // IMPLEMENTAR:
    // getAll(): T[]
}

Teste obrigatório:

// main.ts
const favUsers = new Favorites();
favUsers.add(user1);
favUsers.add(user2);
favUsers.remove(user1);
console.log(favUsers.getAll());

const favTasks = new Favorites();
favTasks.add(task1);
console.log(favTasks.exists(task1));
