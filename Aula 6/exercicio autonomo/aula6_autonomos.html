Exercícios Autónomos — Generics em TypeScript (Extensão do Projeto)

Objetivo geral:
Aplicar generics em funcionalidades novas do sistema de gestão de tarefas e utilizadores, criando componentes reutilizáveis, tipados e integráveis no projeto real.

Exercício A1 — Sistema genérico de etiquetas (Tags)

Ficheiro: utils/TagManager.ts

Contexto:
Adicionar tags a:

  • tarefas (ex: bug, urgente, frontend, backend)
  • utilizadores (ex: admin, remoto, junior)

Objetivo:
Criar um gestor genérico de etiquetas reutilizável.

  • Cada item pode ter várias tags
  • Tags são strings

  • getTags(item: T): string[]

    // private tags: Map

    // IMPLEMENTAR:
    // addTag(item: T, tag: string): void

    // IMPLEMENTAR:
    // removeTag(item: T, tag: string): void

    // IMPLEMENTAR:
